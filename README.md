# Cemzo Store

## Project Overview
A responsive product listing page built with React using the DummyJSON products API.

## Features
- Product listing
- API integration
- Search by product title
- Loading state
- Error state
- Empty state
- Responsive design

## Technologies
- React
- JavaScript
- HTML
- CSS

## API
https://dummyjson.com/products

## How to Run
```bash
npm install
npm run dev
```

The project focuses on the core requirements given in the technical assignment.
