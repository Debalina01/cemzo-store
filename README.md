# Cemzo Store

## Live Demo

[View Live Website](https://cemzo-store-alpha.vercel.app/)

## Project Overview

A responsive product listing page built with React using the DummyJSON products API.

## Features

* Product listing
* API integration
* Search by product title
* Loading state
* Error state
* Empty state
* Responsive design

## Technologies

* React
* JavaScript
* HTML
* CSS
* Vite

## API

[DummyJSON Products API](https://dummyjson.com/products)

## How to Run

```bash
npm install
npm run dev
```
